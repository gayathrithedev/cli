CHANGED ASSUMPTION

The previous design assumed locally acquired checkpoint context could be rendered
and spoken once retrieved.

That assumption is no longer sufficient:

- prompts/transcripts may be redacted or unavailable,
- raw content must not cross a new external-service boundary,
- incomplete context must be visible in every renderer,
- and browser speech implementations may use non-local voice services.

REVISED PRIVACY DESIGN

Implement the integration and privacy boundary together.

1. Keep all checkpoint reconstruction and deterministic synthesis local.
2. Add no external summarizer, analytics, telemetry, CDN, remote font, external
   API, or third-party browser request.
3. Do not send raw prompts or transcripts to Graph.
4. Graph runtime questions may contain only code symbols, relations, and file
   locations.
5. Introduce an explicit context-completeness state, using source-grounded names
   equivalent to:
   - complete
   - partial
   - redacted
   - unavailable
6. Include machine-readable reasons for partial/redacted/unavailable context.
7. Propagate completeness consistently through ReviewBundle, terminal output,
   JSON, GET /api/review, browser cards, evidence and continuation output.
8. When required evidence is redacted or unavailable:
   - retain safe checkpoint/session/commit identifiers,
   - retain safe changed-file and diff information,
   - produce useful continuation guidance,
   - downgrade affected claims to inference/question/uncertain,
   - never label the overall review complete or authoritative.
9. Do not expose redacted values in error messages, logs, evidence excerpts,
   terminal output, JSON, API responses, HTML, speech text or test snapshots.
10. Preserve existing terminal and --json behavior for complete checkpoints.
11. Bind the local web server only to 127.0.0.1.
12. Serve only embedded assets and the read-only review endpoint.
13. Add a restrictive same-origin Content Security Policy.
14. Ensure browser JavaScript makes no cross-origin requests.
15. Use only local browser speech voices where:
    voice.localService === true
16. If no confirmed local voice is available:
    - disable speech,
    - show a clear privacy explanation,
    - preserve complete keyboard/text functionality.
17. Do not silently fall back to a remote voice.
18. Never place raw transcript or prompt text into HTML using innerHTML.
19. Do not serve arbitrary repository files or raw checkpoint files.
20. Keep fixture mode explicit and visibly marked as fixture data.
